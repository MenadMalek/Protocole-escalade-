# Protocole du cycle d’escalade

Outil destiné aux équipes éducatives pour construire un protocole individualisé de gestion des situations de crise à partir du cycle de l’escalade.

- **Utiliser l’outil :** ouvrir `index.html` via le site GitHub Pages.
- **Mode d’emploi :** accessible directement depuis le bouton « 📖 Mode d’emploi » dans l’outil.
- **Auteur :** Menad Malek — Éducateur spécialisé.

Les données saisies sont enregistrées localement dans le navigateur. Elles ne sont pas envoyées automatiquement sur GitHub.
